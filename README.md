# 1. Project Overview
EduHunt is an interactive, gamified elementary mathematics learning platform designed to make math engaging for students while providing powerful management and diagnostic tools for teachers. By combining island-based game progression with adaptive AI-powered practice and real-time classroom analytics, EduHunt bridges the gap between self-paced student learning and structured instruction.

# 2. Key Objectives
- Enhance Student Engagement: Transform abstract math concepts into interactive island maps, leveling systems, and reward points (XP).
- Deliver Personalized Practice: Utilize AI to generate targeted practice quizzes tailored to student skill levels across various topics.
- Streamline Teaching Operations: Provide educators with end-to-end classroom management—from content creation and access control to automated student tracking.
- Foster Peer Collaboration: Offer structured discussion boards for students to ask questions, assist peers, and view teacher announcements.

# 3. Core Features
# Student Portal
- Gamified World Map (Home): Visual island progression system where completed lessons unlock new map areas, levels and XP.
- Structured Modules (Modules): Access topic notes, guided lessons and subtopic quizzes organized by chapters (e.g., Ancient Pyramid: Fundamentals).
- Adaptive AI Practice (Math Helper): On-demand quiz generator allowing students to choose specific topics, subtopics and difficulty settings (Beginner, Intermediate, Advanced).
- Classroom Forum (Discussion): Interactive Q&A board to collaborate with classmates and receive updates from teachers.
- Learning Log (History): Complete overview of island progress, past quiz performances and AI practice history.

# Teacher Portal
- Classroom Analytics Dashboard: Real-time visibility into overall class skill distribution, student rankings and topic mastery levels.
- Chapter & Content Creator: Simple builder to configure new chapters, upload learning materials (slides/files), select island themes and design custom quiz questions.
- Granular Access Control: Lock or unlock specific island chapters to keep student progression aligned with classroom pacing.
- Detailed Progress & Feedback: Filter students by performance status (Mastering, Struggling), generate AI summaries and review granular response distribution charts down to individual quiz options.
